# App Review 提出メモ

最終確認日: 2026-09-06

App Store Connect の「審査メモ」へ転記するための下書きです。`【要入力】` は提出前に実在するテスト専用情報へ置き換えます。本番利用者のアカウントは記載しません。

## アプリの概要

本アプリは、SNS経由の案件、予定、ファイル紐付け、報酬を管理するアプリです。**個人機能はログイン不要**で利用できます。ログインは個人クラウドバックアップとチーム共有に必要です。

## 審査用ログイン

- Google デモアカウント: `【要入力: 審査専用メール】`
- パスワード: `【要入力: 審査専用パスワード】`
- Appleログインは審査端末のApple IDでも確認できますが、チーム機能の確認には上記デモアカウントを推奨します。
- デモアカウントには、案件・予定・報酬のサンプルと、参加済みの審査用チームを用意してください。

## 主な確認手順

### ログイン不要の個人機能

1. アプリを起動します。
2. 右下の `＋` から個人案件を追加します。
3. 上部の予定アイコン、報酬アイコン、設定を開きます。
4. 端末内だけで個人案件を作成・編集できることを確認します。

### ログインとチーム機能

1. 設定 → ログイン → Googleログインを開き、デモアカウントでログインします。
2. 左上メニュー → チームを開き、審査用チームを選びます。
3. チーム案件、予定、メンバー、報酬、履歴を確認します。
4. 一般メンバーはチーム設定の権限に従い、非公開情報や他メンバーの経費を閲覧できません。

### アカウント削除

1. 設定 → ログインを展開し、`アカウントを削除` を押します。
2. Google / Apple で本人確認をやり直します。
3. 管理者のチームがある場合は、管理者移管またはチーム解散を選びます。一般メンバーのチームは脱退になります。
4. 確認欄へ `削除`（英語表示は `DELETE`）と入力し、削除を確定します。
5. クラウドデータと認証アカウントが削除され、端末内データは利用者が別チェックを選んだ場合だけ消去されます。

審査中にアカウント削除を試す場合は、削除後に再確認できるよう、使い捨ての審査専用アカウントを別途記載してください。

## 外部サービスと課金

- 認証・クラウド同期: Firebase Authentication / Cloud Firestore / Cloud Functions
- Googleログイン、Sign in with Appleを利用します。
- 現在、広告、アプリ内課金、サブスクリプション、外部決済リンクはありません。
- Firebase Analytics / Crashlytics / Performance Monitoring は導入していません。
