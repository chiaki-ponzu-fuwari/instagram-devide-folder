# 将来の広告・課金 導入前チェックリスト

最終確認日: 2026-09-06

**現在、広告とアプリ内課金は未導入です。** この文書は将来導入するときの公開条件であり、現バージョンに広告・有料機能があるという説明ではありません。

## 広告を追加する前

- [ ] 広告SDKの公式Privacy Manifest、署名、収集データ、送信先ドメインを確認
- [ ] 可能なら最初は横断追跡を行わない広告方式を選択
- [ ] 横断追跡または広告識別子を使う場合だけ ATT を実装
- [ ] ATT許可前には追跡SDKを起動・送信しない
- [ ] ATTを拒否しても、主要機能を利用できるようにする
- [ ] `NSUserTrackingUsageDescription` を、実際の目的が分かる文へ更新
- [ ] `PrivacyInfo.xcprivacy`、App Store Connectのプライバシー回答、プライバシーポリシーをSDK実態に合わせて更新
- [ ] 子ども向けの広告・年齢区分・地域別同意（GDPR等）が必要か確認
- [ ] 実機で通信先と同意前後の送信差を確認

追跡を行わない広告だけであれば、不要なATTダイアログは出しません。

## 有料機能・サブスクリプションを追加する前

- [ ] デジタル機能の解放、広告削除、サブスクリプションには StoreKit 2 のアプリ内課金を使用
- [ ] 商品名、価格、期間、自動更新、無料体験終了後の料金を購入確定前に表示
- [ ] `購入を復元` を目立つ場所へ追加し、別端末でも復元を確認
- [ ] 購入成功、失敗、保留、キャンセル、Ask to Buy、期限切れを処理
- [ ] `Transaction.currentEntitlements` またはサーバー検証で権利状態を確認
- [ ] アカウント削除と購読解約は別であることを削除画面と利用規約へ表示
- [ ] 購入前表示、解約方法、返金窓口、家族共有の扱いを利用規約・サポートへ追加
- [ ] App Store Connectへ利用規約URLとプライバシーポリシーURLを登録
- [ ] 日本向けに価格、支払時期、提供内容、解約条件を購入確定直前に確認できるようにする
- [ ] 外部購入への誘導文やボタンを、対象ストアの最新ルールなしに追加しない

## リリース判定

広告または課金を含む版は、次の4点が一致するまで提出しません。

1. アプリの実際の通信・画面
2. `PrivacyInfo.xcprivacy` とSDK同梱manifest
3. App Store Connectのプライバシー・課金情報
4. プライバシーポリシー、利用規約、サポート文面

参考: [Apple App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/)、[Apple User Privacy and Data Use](https://developer.apple.com/app-store/user-privacy-and-data-use/)
