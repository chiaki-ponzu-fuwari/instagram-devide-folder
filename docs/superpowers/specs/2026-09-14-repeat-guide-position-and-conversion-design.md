# 継続案件ガイドの位置と単発からの切替 Design

## 目的

継続案件リストの「使い方ガイド」を、他ページと同じく画面下部に常時表示する。初めて継続案件を使う人が、単発案件を後から継続案件に変える方法も理解できるようにする。

## 画面

- 継続案件リストの見出しと案件一覧だけをスクロール可能にする。
- 「使い方ガイド」は一覧の件数に左右されず、画面下部に残す。
- 既存のボタンサイズ、色、文言、初回バウンド表示は変更しない。

## ガイド本文

既存の用途・登録・編集・例に加え、次の節を追加する。

### 単発案件が継続になった時

1. 元の単発案件を開く。
2. 契約タイプで「継続案件」を選び、保存する。
3. 元の案件は最初の子案件として残る。
4. 次回からは、その継続案件内で子案件を追加する。

この操作は既存の `saveProject` と `createRepeatChild` の挙動を説明するだけであり、案件の保存・集計・親子関係のロジックは変更しない。

## 検証

- DOM回帰テストで、継続案件のガイドバーがスクロール領域の外にあることを確認する。
- DOM回帰テストで、単発から継続へ変更した時の説明文を確認する。
- `npm test`、JavaScript/HTML構文、差分の空白チェックを実行する。
