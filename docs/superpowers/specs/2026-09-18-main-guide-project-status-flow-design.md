# 案件一覧ガイド：案件管理のステータス説明

## 目的

案件一覧の「使い方ガイド」で、案件管理画面の「納品済 → 入金確認済 → 終了」が分かりにくい問題を解消する。

## 方針

- 既存の「2. 案件を登録する」を厚くする（独立セクションは作らない）
- ステータスの流れは詳しく書く
- その他の入力項目（案件名・日時・報酬・経費など）は短く触れるだけ
- 1, 3〜7 の項目は変更しない

## 反映先

- `www/index.html` の `PAGE_GUIDE_CONTENT.main`
- `tests/personal-page-guide-ui.test.mjs` で主要文言を固定

## 承認済み文面の要点

- 相談中 → 契約中 → 納品済 → 終了
- 報酬がある案件は、納品済のあと「入金確認済」チェックを入れてから終了にする
- 流れの要約: 納品済 →「入金確認済」にチェック → 終了
