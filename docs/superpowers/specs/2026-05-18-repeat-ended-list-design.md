# 継続案件の契約終了済み表示設計

## 目的

継続案件リストの中で、契約終了した親案件を完全に消さず、最下部に薄いグレーで残せるようにする。
これにより、過去の継続案件を後から確認できるようにしつつ、通常の継続案件と視覚的に分離する。

## 仕様

### 表示

- 継続案件リストは、通常の継続案件と契約終了済み案件の2領域に分ける。
- 通常の継続案件は従来どおり表示する。
- 契約終了済み案件は、リストの最下部に薄いグレーで表示する。
- 契約終了済み案件には「契約終了」バッジを付ける。
- 契約終了済み案件は、通常案件より弱い見た目にして、誤操作しにくくする。

### 設定

- 設定ページの「終了済案件の表示設定」に、新しい項目「継続案件の契約終了済み案件の表示設定」を追加する。
- 形式は `一覧に表示 / 非表示` の2択にする。
- この設定は継続案件リストの契約終了済み表示だけに効かせる。
- 既存の案件一覧、フォルダ一覧、検索結果、報酬集計には影響させない。

### 契約終了の扱い

- 親案件の契約終了は、未終了の子案件が残っている場合は実行できない。
- すべての子案件が終了済みのときだけ、契約終了を確定できる。
- 契約終了後も、子案件と報酬データは削除しない。
- 契約終了済みの親案件は、継続案件リストの通常領域から外し、契約終了済み領域へ移す。

## UIの考え方

- 継続案件リストの上部構造は変えない。
- 契約終了済み案件は、一覧の最後にまとまって出す。
- 契約終了済み領域は、通常領域よりも余白を狭くして、見た目の重さを抑える。
- ユーザーが一覧をスクロールした時、終了済み案件は「履歴」として自然に見える位置に置く。

## データの扱い

- 既存の `repeatClosedAt` を契約終了済み判定に使う。
- 契約終了済み案件の子案件は、そのまま保持する。
- 子案件の内容、報酬情報、終了済み状態は変更しない。
- 表示設定は既存の `S.meta` のフラグとして保存する。

## テスト観点

- 継続案件を契約終了すると、通常一覧から外れ、契約終了済み領域に出る。
- 設定を `非表示` にすると、契約終了済み案件は継続案件リストに出ない。
- 子案件が残っている状態では契約終了できない。
- 契約終了済み案件の表示/非表示は、他の一覧に影響しない。
