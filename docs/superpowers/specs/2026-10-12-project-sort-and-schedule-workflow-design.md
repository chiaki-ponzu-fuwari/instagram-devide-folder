# 案件一覧の表示順とスケジュール改善

## 表示順

- すべての表示順を `www/js/project-list-sort.js` に集約
- 進行中と終了済みを分け、終了済みは常に下
- ピン留めは各ブロック内だけで優先

## スケジュール

- チェックで撮影/下書き/投稿を一覧から非表示（確認モーダル付き）
- 撮影日あり・投稿日なしは黄色系で強調
- タブを「スケジュール / 要確認 / カレンダー」の3つに
- 案件タップで案件管理を直接開く

## その他

- 案件カード右の「管理」で案件管理を開く
- NEW DMフラグ解除時に案件データが消えないよう、編集保存で既存 project を保持
