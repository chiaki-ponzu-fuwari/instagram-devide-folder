# チーム作成数制限（無料枠）設計

## 目的

無料利用では、1つのアカウントが同時に作成できるチームを1つまでにする。参加するチーム数は制限しない。将来のサブスクリプションで作成可能数を増やせる形にする。

## 利用者の見え方

- 自分が作成した有効なチームがない場合は、これまでどおりチームを作成できる。
- すでに1つ作成済みの場合は、新規チームを作成できず、「無料プランではチームを1つまで作成できます」と表示する。
- チームを解散すると作成枠が戻り、別のチームを作成できる。
- 他人のチームへの参加・退出には影響しない。
- 既に複数チームを作成しているアカウントのチームは削除せず、追加作成だけを止める。

## データと強制方法

`teamCreatorSlots/{uid}` を作成者ごとの作成枠として使う。現在は `activeTeamId` を1つだけ持つが、将来はプランごとの上限値に置き換えられる。

チーム作成時は、チーム文書・管理者メンバー文書・作成枠を同じ Firestore batch で作成する。Firestore Rules は、作成枠を同時に確保していないチーム作成と、既に枠を持つアカウントの追加作成を拒否する。画面側の判定だけには依存しない。

既存チームの作成者には、最初のチーム一覧取得時に既存作成チームを指す作成枠を冪等に補完する。補完できない場合も新規作成を許可せず、データ保護を優先する。

チーム解散時は、削除対象チームと一致する作成枠だけを同じ batch で解除する。

## エラー処理

- 通信失敗時は新規作成を完了扱いにしない。
- 枠が既に使われている場合は専用エラー `team-creation-limit` を返し、分かりやすい日本語を表示する。
- 解散済みチーム以外の作成枠を解除しようとする操作は Rules で拒否する。

## テスト

1. 新しいアカウントは、チームと作成枠を同時に作成した場合だけ1チーム作成できる。
2. 作成枠なしの単独チーム作成、作成枠だけの作成、作成済みアカウントの2件目作成は拒否される。
3. 他人の作成枠の作成・参照・解除は拒否される。
4. 解散した本人は対応する作成枠を解除でき、新しいチームを作成できる。
5. 参加チーム数は制限されない。
6. 既存の作成チームを持つアカウントは、補完された枠により追加作成を防げる。

## 非対象

- サブスクリプション課金、購入復元、プラン選択UI。
- 既存の複数チームを自動削除・自動解散すること。
